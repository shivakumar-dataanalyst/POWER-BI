# E-Commerce Sales Analysis – Power BI

## Project Overview

This project is based on Power BI Assignment 1 – Data Transformation & Data Modeling.

The objective is to transform, clean, merge and model e-commerce sales data using Power BI.

## Data Sources

- List of Orders
- Order Details
- Sales Target

## Data Transformation

- Restricted List of Orders to first 500 rows
- Changed Order Date to Date data type
- Changed Amount and Target to Fixed Decimal Number
- Converted CustomerName to Proper Case
- Created Location column using City and State
- Created Profit Margin
- Created Profit Status
- Merged List of Orders and Order Details using Order ID

## Data Analysis

- Count of each Order ID
- Average Profit by Category
- Total Amount by Sub-Category
- Monthly Sales Target

## Data Modeling

Relationships were created using:

- Order ID
- Category

## Tools Used

- Microsoft Power BI
